# 💻 Вкладка: База знаний команд и шпаргалка (tab_commands)

**Updated:** 2026-11-16 01:33:00  
**Автор:** hypo69  
**Пакет:** `apps.common.webgui.tab_commands`

## 📖 Назначение
Вкладка предоставляет пользовательскую базу знаний команд, сниппетов и сценариев системного администрирования (CheatSheet) с интерактивным веб-редактором, копированием в один клик и безопасным выполнением в консоли.

## 🚀 Возможности
- Интерактивный поиск по названию, командам, описанию и тегам.
- Фильтрация по категориям (Git, Docker, Сеть, Система, Windows, Python) и типам оболочки.
- Встроенный модальный редактор команд (`#modal-command-editor`).
- Интерактивный запуск команд с подстановкой параметров `<PARAM>` и выводом результата.
- Переключение избранного и копирование текста команд в буфер обмена.
- Markdown-экспорт шпаргалки (`#pill-cmd-markdown`).
- Полная локализация и поддержка тем оформления.
