## 📋 Описание модуля

Модуль интерфейса **«Чат ассистента»** (`tab_chat`) предоставляет интерактивный экран общения с локальными и облачными языковыми моделями в контексте текущего активного рабочего пространства.

Интерфейс поддерживает мультиязычные контекстные подсказки (Prompt Chips), постановку задач через кнопку `משימה` (`Задача` / `Task` / `Завдання`) с привязкой к базе знаний и календарю, добавление фактов, отображение источников цитирования и полное соответствие RTL (кнопки управления расположены строго снизу под увеличенным полем ввода и выровнены вправо в RTL-режиме).

---

## 🎯 Основные возможности

1. **Контекстные быстрые подсказки (Prompt Chips)**:
   - Автоматическая динамическая генерация подсказок на основе коммитов Git, файлов, проиндексированных документов и сущностей базы знаний.
   - Поддержка языков: `ru`, `en`, `he`, `uk` с автоматическим fallback при пустой рабочей области.

2. **Постановка и координация задач из чата (`משימה` / `Задача`)**:
   - Кнопка `#chat-add-task-btn` (`addTaskFromChat()`) и команды `/task`, `/задача`, `משימה:` ставят задачу в контексте рабочей области.
   - Автоматически учитывается согласованное время из базы знаний (например, визит к Шмулику на утреннюю дойку **20.11.2026 в 06:00** по адресу `מושב נהלל, משק מס' 42` для ветеринара `veterinarian@davidka.net` и страхового агента `attorney@davidka.net`), формируется `.ics` с `VALARM` и фиксируется в Git и `TaskOrchestratorService`.

3. **Интеграция с базой знаний и RAG**:
   - Вопросно-ответная система по фактам рабочего пространства через `KnowledgeQAEngine`.
   - Просмотр цитат источников и связанных сущностей.

4. **Синхронизация с активным пространством**:
   - Автоматическое обновление контекста чата при смене активного рабочего пространства.
   - Поддержка сценариев Telegram-бота и WebGUI.

---

## 🔌 API эндпоинты

- `GET /api/v1/workspaces/{workspace_id}/suggested-questions` — генерация контекстных быстрых подсказок по содержанию рабочей области.
- `POST /api/v1/ask` — запрос к вопросно-ответной системе базы знаний.
- `POST /api/v1/workspaces/{workspace_id}/tasks` — постановка задачи из чата с фиксацией в Git, оркестраторе задач и календаре.
- `POST /api/v1/workspaces/{workspace_id}/facts` — добавление факта из чата в базу знаний и Git.
- `GET /api/v1/workspaces/active` — получение текущей активной рабочей области.
