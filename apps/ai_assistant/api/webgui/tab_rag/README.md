# Вкладка: 5-этапный поиск RAG & База знаний (tab_rag)

Вкладка гибридного семантического и фактологического поиска (NLP + SQLite + FAISS + LLM) по изолированной пользовательской базе знаний каждой рабочей области (РО / User Space).

## Возможности
- **Изолированный RAG для каждой РО:** Каждая рабочая область обладает собственным хранилищем документов (`knowledge_store.db`) и векторным индексом FAISS (`.workspace/faiss_indices/ws_<workspace_id>`).
- **5-этапный конвейер RAG:** Разбор намерения (NLP) → Поиск фактов (SQLite) → Векторный RAG (FAISS) → Верификация непротиворечивости → Синтез ответа (LLM/Morpho).
- **Построение RAG:** Кнопки «Построить RAG» для текущей выбранной РО и «Собрать для всех РО» (`POST /api/v1/workspaces/{id}/rag/build`, `POST /api/v1/workspaces/rag/build-all`).
- **Индикатор статуса RAG:** Отображение статуса готовности индекса (число документов, чанков и векторов).
- **URL-маршрутизация:** Поддержка прямых ссылок формата `#tab-rag#workspace=<workspace_id>`.
- **Селектор рабочей области:** Мгновенное переключение контекста и синхронизация с верхним навигационным меню через событие `context:changed`.
- **Доказательная база источников:** Отображение документов-первоисточников, номеров предложений, точных цитат и семантических совпадений FAISS.
- **Инспекция чанков (`panel-rag-chunks`):** Таблица сегментов документов выбранного воркспейса с SHA256 и контролем версий.

## Структура
- `panel_rag/`: Изолированная панель `panel-rag-chunks`, взаимодействующая с `GET /v1/panel/panel-rag-chunks`, `POST /api/v1/query`, `GET /api/v1/workspaces/{id}/rag/status` и `POST /api/v1/workspaces/{id}/rag/build`.
- `main.js`: Клиентский оркестратор вкладки с поддержкой `context:changed` и `hashchange`.
- `index.html`: Разметка интерфейса вкладки без хардкода строк (строго токены `{{...}}` и словари `locales`).
