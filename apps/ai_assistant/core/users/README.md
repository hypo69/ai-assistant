# Управление пользователями и профилями (Users Module)

Модуль управления пользователями, профилями и учетными записями в системе AI-Assistant.

## Назначение

- Управление базой данных пользователей `data/users.db` (SQLite с поддержкой WAL-режима).
- Хранение профиля активного пользователя (имя, логин, email, фото/аватар, роль, настройки).
- Автоматическая синхронизация профиля при авторизации через Google OAuth 2.0 (получение аватара из Google profile / `id_token` / Gravatar).
- Предоставление информации о профиле для WebGUI (шапка приложения, модальное окно настроек).

## Структура

- `models.py` — модель данных `UserModel` и сериализация.
- `storage.py` — потокобезопасный слой хранения `UsersStorage` поверх `data/users.db`.
- `service.py` — бизнес-логика `UserService` и синглтон `user_service`.
