# 💻 Пользовательская база знаний команд (User Commands)

**Updated:** 2026-11-16 01:25:00  
**Автор:** hypo69  
**Пакет:** `apps.ai_assistant.core.user_commands`

## 📖 Назначение
Модуль предназначен для централизованного хранения, поиска, классификации и интерактивного выполнения пользовательских команд и сценариев в операционной системе Windows.

## 🚀 Возможности
- Хранение команд с привязкой к оболочкам (`PowerShell`, `CMD`, `Bash`, `Python`).
- Категоризация, тегирование и полнотекстовый поиск.
- Поддержка параметров и плейсхолдеров (`<PARAM>`).
- Интерактивный запуск команд на локальной машине с замером времени и фиксацией вывода `stdout` / `stderr`.
- Двустороннее зеркалирование в Markdown-шпаргалку (`data/user_commands/commands_cheatsheet.md`).
- Избранное и счётчик частоты выполнения.
