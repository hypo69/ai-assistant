# 📬 Microsoft Outlook Skill

Навык для работы с почтой Microsoft Outlook / Office 365 через API микросервиса `apps/microsoft`.

---

## 🚀 Возможности
1. Проверка статуса учетной записи и параметров подключения.
2. Выборка последних писем по IMAP/Graph.
3. Отправка писем через защищенный шлюз SMTP Office 365.
